# Código de conducta

Este proyecto sigue el [Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/codigo-de-conducta/) versión 2.1.

## En pocas palabras

- Treatá a las personas con respeto. Este proyecto lo mantiene una persona y recibe contribuciones de otras.
- Discutamos el código, no a la persona. Las críticas van con argumentos y propuestas.
- Nadie tiene que tolerar acoso, insultos niHumillaciones públicas.

## Reportes

Si algo no está bien, escribime a `melorenzo@fullware.com.ar` o abrí un issue privado en el repositorio. Los reportes se manejan de forma confidencial.

## Aplicación

Las mismas reglas aplican a issues, pull requests, comentarios y cualquier espacio del proyecto.
